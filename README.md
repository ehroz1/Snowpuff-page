# Snowpuff — сайт

Лендинг для [Snowpuff](https://github.com/ehroz1/Snowpuff), живёт на https://snowpuff.ehroz.pro.
Другие приложения автора — на [ehroz.pro](https://ehroz.pro).

Статика без сборки:

- `index.html` — страница (русский текст прямо в разметке);
- `i18n.js` — английская версия и выбор языка: `?lang=en|ru`, затем выбор посетителя, затем язык системы;
- `site.js` — ссылки на скачивание под систему посетителя, переключатель macOS/Windows, кнопка языка;
- `snow.js` — живой снег: падает, оседает на окнах и сугробах, разлетается от курсора, слушает микрофон;
- `style.css` — стили.

Публикация через GitHub Pages из корня `main`, домен задан в `CNAME`.
